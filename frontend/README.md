# Ajab Flour Digital Hub

A web application prototype for Ajab Flour Company, built as a portfolio project for a software engineering attachment application.

## 🎯 Project Purpose

This project demonstrates web development skills and provides a functional prototype of a digital platform that can help Ajab Flour Company:

1. **Market products** across Africa
2. **Manage bulk orders** from retailers, hotels, and institutions
3. **Track inventory** automatically
4. **Provide 24/7 customer support** via AI chatbot
5. **Admin dashboard** for business operations management

## 🚀 Features

### Customer-Facing Website
- Product catalog with filtering
- Bulk order inquiry system
- Country-specific registration with flag emojis
- Find retailers feature
- Integrated customer care (chatbot, WhatsApp links)
- Responsive design for all devices

### Admin Dashboard
- Real-time business statistics
- Order management system
- Product management with image upload
- Inventory tracking with alerts
- Customer analytics by country
- Sales monitoring

### Technical Features
- User authentication (JWT)
- RESTful API with Node.js/Express
- PostgreSQL database
- AI-powered FAQ chatbot
- Country code selection with flags
- Image upload functionality
- Responsive UI with modern design

## 🛠️ Technology Stack

### Frontend
- HTML5, CSS3, JavaScript 
- Chart.js for data visualization
- Responsive design with CSS Grid/Flexbox
- Font Awesome icons

### Backend
- Node.js with Express.js
- PostgreSQL database
- JWT for authentication
- bcryptjs for password hashing
